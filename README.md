# 오시마켓 (Oshi Market)

서브컬쳐(애니메이션·게임) 굿즈 마니아층을 위한 **중고거래 + 구매처 큐레이션 플랫폼**

## 프로젝트 목적

서브컬쳐 굿즈는 정식 판매처가 공식몰, 애니메이트, 각종 예약판매 사이트 등으로 분산되어 있고,
중고거래는 당근마켓·중고나라 같은 일반 플랫폼에서 이루어져 신뢰성과 검색 편의성이 떨어진다.
이를 하나로 모아 **중고거래 안전성**과 **구매처 정보 접근성**을 함께 제공하는 것이 목표다.

자세한 기획 배경은 [`프로젝트_기획서.md`](./프로젝트_기획서.md) 참고.

## 주요 기능

MVP 스코프는 [`1_MVP기획서.md`](./1_MVP기획서.md) 참고.

- 굿즈 중고거래 (등록/검색/거래)
- 작품·캐릭터별 굿즈 구매처 큐레이션 (공식몰, 예판 사이트 링크 모음)
- 태그/카테고리 검색 (작품명, 캐릭터명, 굿즈 종류)
- (2차 개발) 실시간 채팅, 관심 굿즈 알림, 판매자 신뢰도(거래 후기, 평점) 시스템

## 기술 스택

Java 17 + Spring Boot 3.x · MySQL 8.0 · React · Docker + AWS EC2

상세 선정 이유는 [`2_기술스택분석서.md`](./2_기술스택분석서.md) 참고.
